## 1. 프로젝트 개요

### 1.1 목표

**핵심 가치 제안**:
"웹에서 가볍게 즐기는 빠른 액션 게임 - 30초 안에 액션의 재미를 느낀다"

### 1.2 문제 정의

**현재 문제**:
- 기존 RPG는 무겁고 설치가 필요함 (평균 설치 시간 5-10분)
- 본격적이고 헤비하여 가볍게 즐기기 어려움
- 노가다 요소가 많아 순수한 액션 재미가 희석됨
- 웹 게임은 대부분 액션감이 떨어짐

**해결 방법**:
- 웹 기반으로 즉시 접속 (목표: 3초 이내 로딩)
- 설치 불필요, URL만으로 플레이
- 핵심 액션/콤보에 집중 (노가다 최소화)
- 엘소드 수준의 타격감을 웹에서 구현

**측정 가능한 개선**:
- 접속 시간: 기존 5-10분 → 3초 (99% 개선)
- 첫 전투까지: 기존 10-30분 (튜토리얼) → 30초 (99% 개선)
- 순수 액션 비율: 기존 30% → 90% (3배 증가)

### 1.3 타겟 사용자

**주 타겟**:
- 나이: 20-35세
- 관심사: 액션 게임, 콤보 시스템, 아케이드 게임
- 행동 패턴: 짧은 시간에 강렬한 재미를 원함
- 기술 수준: PC 웹 브라우저 사용 가능
- 플레이 시간: 30분-1시간 (점심시간, 퇴근 후)

**참고 게임 경험**:
- 엘소드 (콤보, 액션)
- 크루쉐이더 퀘스트 (수집)
- 엘든링 (탐험, 자유도)
- Katana ZERO, Hotline Miami (네온 레트로)

### 1.4 차별화 요소

| 항목 | 경쟁사 (엘소드) | 쾌쾌쾌 | 개선율 |
|------|----------------|--------|--------|
| 접속 방식 | 클라이언트 설치 필요 | 웹 URL 즉시 접속 | 99% 빠름 |
| 로딩 시간 | 5-10분 (설치+패치) | 3초 | 99% 빠름 |
| 노가다 요소 | 높음 (던전 반복) | 최소화 | 70% 감소 |
| 비주얼 스타일 | 3D 애니메이션 | 네온 코믹 (독특) | 차별화 |
| 진입 장벽 | 높음 (복잡한 시스템) | 낮음 (간단한 콤보) | 60% 감소 |

## 3. 게임 메커니즘

### 3.1 장르 & 스타일

**장르**: 2D 횡스크롤 액션 RPG
**시점**: 사이드뷰 (옆에서 보는 2D)
**플랫폼**: 웹 (PC 우선, 모바일 v2.0)

### 3.2 조작 방식

**이동**:
- 좌우 이동: A/D 또는 ←/→
- 점프: W 또는 ↑ 또는 Space
- 중력 + 충돌 감지

**전투**:
- 기본 공격: Z 또는 J (3연타 콤보)
- 스킬 1: Q (돌진 베기)
- 스킬 2: W (회오리)
- 스킬 3: E (띄우기)

**목표 반응 속도**: 입력 지연 < 50ms

### 3.3 전투 템포

**템포**: 빠른 액션 (엘소드 스타일)
- 공격 속도: 1초에 2-3타
- 스킬 쿨다운: 3-7초
- 콤보 리셋: 1초 (타격 없으면)

### 3.4 콤보 시스템 (핵심 재미)

#### **간소화된 콤보**

**기본 공격 (Z키)**:
```
1타: 빠른 찌르기 (0.3초)
└─> 2타: 회전 베기 (0.3초)
    └─> 3타: 강한 마무리 + 넉백 (0.4초)
```

**스킬 (Q/W/E)**:
```
Q: 돌진 베기 (이동 + 공격, 쿨다운 3초)
W: 회오리 (범위 공격, 쿨다운 5초)
E: 띄우기 (공중 콤보용, 쿨다운 7초)
```

**캔슬 시스템**:
- 기본 공격 중 스킬 캔슬 가능 ✅
- 스킬 후 기본 공격 이어지기 ✅
- 콤보 카운터 표시 ✅

**예시 콤보**:
```
입문: Z → Z → Z (3연타)
중급: Z → Z → Q (2타 캔슬 돌진)
고급: E → Z → Z → W (띄우기 → 콤보 → 마무리)
최고: Z → Q → Z → Z → W (복합 캔슬)
```

**성공 기준**:
- 최소 5타 이상 콤보 가능
- 콤보 느낌이 자연스러움
- 타격감 있음 (히트스톱, 화면 흔들림, 효과음)

## 5. 기술 스택

### 5.1 프론트엔드

**게임 엔진**:
- **Phaser.js v3.80+**: 2D 게임 프레임워크
  - 선택 이유: Unity 경험자에게 익숙한 Scene 구조, 물리/충돌 내장, 1개월 MVP 가능

**언어 & 빌드**:
- **TypeScript v5.0+**: 타입 안정성
- **Vite**: 빠른 빌드 도구
- **ESLint + Prettier**: 코드 품질

**대안 비교**:
| 항목 | Phaser.js | PixiJS |
|------|-----------|--------|
| 학습 시간 | 2-3일 | 1주일+ |
| 내장 기능 | 물리, 충돌, Scene | 렌더링만 |
| 1개월 MVP | ✅ 가능 | ❌ 시간 부족 |

### 5.2 백엔드 (v1.0에서 추가)
